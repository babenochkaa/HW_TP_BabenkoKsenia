# Recipes Project

Проект для работы с рецептами, ингредиентами и списком покупок.

## Описание

В проекте реализованы классы:

- `Ingredient` — ингредиент рецепта;
- `Recipe` — обычный рецепт;
- `DietaryRecipe` — рецепт с диетической категорией;
- `ShoppingList` — список покупок по рецептам.

## Установка

Склонируйте репозиторий:

git clone <ссылка-на-репозиторий>
cd HW_TP_Babenko
